``` r

    route1:route11,
    entry,
    vending,

  )
```

``` r
transit_df = 
  transit_df |> 
  mutate(
    entry = case_match(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    )
  )
```

This dataset contains information about entrances and exits for NYC
subway stations. It includes the subway line, station name and location,
routes served, entrance type, whether entry is allowed, vending
availability, and ADA compliance. I cleaned the data by standardizing
variable names, retaining only the variables relevant to the analysis,
and converting the `entry` variable from a character variable (`YES` /
`NO`) to a logical variable (`TRU`E / `FALSE`). After cleaning, the
resulting dataset contains 1868 rows and 19 columns. These data are not
tidy because the routes served by each station are spread across
multiple columns, instead of being stored as values of a single route
variable.

``` r
prop_entry_no_vending = 
  transit_df |> 
  filter(vending == "NO") |> 
  summarize(
    proportion = mean(entry)
  ) |> 
  pull(proportion)
```

Among station entrances/exits without vending, 37.7% allow entrance.
